サーカスのゾウは、長年の[[調教]]によっておとなしくなったと信じている人が多い。しかし、実際はそうではない。調教なんかしなくても杭に二週間もつないでおけば、どんな象でもおとなしくなる。杭につながれているロープを断ち切って逃げようと象がもがくのは、[[せいぜい]]最初の数日間だけだという。その後、杭からロープを解き放っても、もはや「無力感にさいなまれた象」がサーカス小屋や動物園から逃げ出すことはない。

過去何十年にもわたって、プロ野球はセ・パ両リーグが六球団だけで戦ってきた。サッカーのように、[[低迷したら]]J1リーグからJ2リーグに降格することもない。

[[たとえ最下位になっても]]、シーズンオフ[[さえ我慢すれば]]、翌年四月には同じスタートラインに立てる。荒波にもまれることのない穏やかな湾内でいつも航海しているから、向上心など生まれる[[わけがない]]。こんな状況で、タイガースの選手に「闘争心をもて!」というほうが無理なのである。

事実、野村前監督は就任一年目の1999年のシーズン終了後に、球団に辞意を[[漏らした]]ことがある。「闘争心が欠けているこのチームを再建することは、自分には不向きである」と申し出たのだ。当時、彼は星野監督のような人間が適任者であることを球団首脳に[[ほのめかしている]]。けっきょく、そのときは慰留されたが、その二年後、野村前監督が考えていたことは現実となった。

彼が果たせなかった「意識革命」を断行する[[闘志]]あふれるリーダーが、タイガースには必要だった。野村前監督が推した星野監督がチームに飛び込んできた。闘争心が[[衰えていた]]タイガースにとって、これはまさに適任人事であった。

星野監督は高知県安芸でのキャンプ中、[[ことあるごとに]]全選手の前で「お前らはできるんだ。優勝できるんだ」という言葉を何度もくり返した。それが選手の心に火をつけた。

雑誌のインタビューでの今岡の言葉がこれを証明している。

「僕らは『目標は優勝だ』なんて[[口が裂けても]]いえなかった。なぜなら周りが笑うからですよ」

野村阪神の失敗は、せっかく素晴らしいものを野村前監督がもっていた[[にもかかわらず]]、人間関係の[[希薄]]さによって、選手が彼のノウハウを吸収できなかったことにあると思われる。これでは勝ちにいくゲームなんかできるわけがない。

星野監督は無言で「オレのもっているものをお前たちは奪えるだけ奪ってくれ」と叫んでいたように思える。星野監督の情熱をそっくりタイガースの選手が受けとったとき、はじめて彼らは「野生の虎」に変身できる。星野は、「動物園の虎」を「野生の虎」によみがえらせようと必死になって頑張っていたのだ。

(児玉光雄『こんな上司となら仕事がしたい 星野仙一が「理想の上司」と言われる理由』河出書房新社による)

(注1) 調教（ちょうきょう）：動物を目的に合わせて訓練すること

(注2) 杭（くい）：地面に打ち込んだ棒

(注3) さいなむ：ここでは、苦しめること

(注4) セ・パ両（りょう）リーグ：日本のプロ野球のセントラルリーグ（6チーム）とパシフィックリーグ（6チーム）、全部で12チーム

(注5) J1リーグ・J2リーグ：日本のプロサッカーリーグ

(注6) シーズンオフ：試合が行われない期間または季節

(注7) タイガース：阪神（はんしん）タイガース。プロ野球球団の一つ

(注8) 慰留（いりゅう）：辞めようとする人を説得し、思いとどまらせること

## 主張理解

```quiz
**1** サーカスのゾウがおとなしくなったのはなぜか。

[ ] 人間によって長い期間訓練を受けたから。
[ ]  人間に従うことでサーカス小屋と動物園の中で自由になれるから。
[c]  人間の支配から逃れるための力がないと思ったから。
[ ]  人間の支配から逃げ出すことは辛いから。

※「無力感にさいなまれた（＝人間の支配から逃れるための力がないと思った）象」が理由を表しているから3が正解。
```

```quiz
**2** タイガースの選手が闘争心をもてなかったのはなぜか。

[c]  プロ野球のシステムでは対抗意識が生まれにくいから。
[ ]  タイガースの選手は野村監督を信頼しなかったから。
[ ]  球団の首脳が野村監督を信頼していなかったから。
[ ]  プロ野球の仕組みに大きな問題があり、監督一人では解決できなかったから。

※「たとえ最下位になっても、翌年四月には同じスタートラインに立てる。向上心など生まれるわけがない」が理由を表しているから1が正解。
```

```quiz
**3** 筆者は星野監督についてどのように述べているか。

[ ] 星野監督は野村前監督のリーダーシップを否定していた。
[ ]  タイガースの選手は星野監督が来ても、優勝できると思えなかった。
[ ]  星野監督はタイガースの選手に自分のノウハウを自ら教えるようにした。

-「思えなかった」ではなく「思えた」
-「自ら教える」とは言っていない
```

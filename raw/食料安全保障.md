## 食料安全保障

政府が進める自国農業の切り捨て政策と，私たちの[[飽食]]のライフスタイルのあり方は，食
料の安定的な[[確保]]（食料安全保障）の[[側面]]や近い将来に予測される[[飢餓]]社会の[[到来]]を[[～を目前に|目前に]]
して，①あまりに楽天的すぎる。大量の食料輸入を背景に，食べ物を[[～てまで|捨ててまで]]，美味しさと
便利さという「快適さ」を追求する飽食社会を維持することは食[[倫理]]の上からも許されるこ
とではない。

今後予想される事態を考えれば，世界貿易の[[円滑]]化と役割分担などという，米国と多国籍
企業のWTO（世界貿易機関）戦略に乗るのではなく，食料自給率を高め，自国の農業生産を
守る政策[[～こそ|こそ]]，食料消費大国である日本が今後取るべき道であろう。持続可能な食料供給と
食料の使い方を[[志向]]しなければならない。

20年前，[[せめて]]10年前の食生活に戻ればどうなのだろう。（中略）飢えてもいなかった
し，[[粗食]]でもなかった。なにも[[禁欲]]や粗食をすすめているのではないが，食糧輸入を増やし
たために化学物質[[汚染]]の危険性が増したり，「快適さ」のために食糧生産に使用した化学物
質が，食料や環境を汚染するという[[愚か]]さは[[再考]]しなくてはならない。命を守り，健康な生
活を送ることこそが私たちの価値基準であり倫理基準でもある。②今後の課題でもあろう。そ
のためにも，私たち自身が食のライフスタイルを考え直す[[～とともに|とともに]]，食料の供給者や行政サ
イドの姿勢に「生活者の健康」という視点がより強く取り入れられることが必要である。

（山口英昌『食環境科学入門 食の安全を環境問題の視点から』ミネルヴァ書房による）

（注1）飽食：生活の中で食料が十分に足りていること
（注2）楽天的：物事をのんきに考えていること
（注3）粗食：粗末な食事のこと

## 読解問題

```quiz
筆者はなぜ①<u>あまりに楽天的すぎる</u>と考えているか。

[c] いろいろな食料問題が起きる可能性があるのに、人々は快適さばかりを求めているから。

[ ] 便利な食生活の背景には、輸入が大きく関係していることに気付いていないから。

[ ] 食べ物を捨ててまで、美味しさや便利さを求める必要はないから。

[ ] 政府の政策により、このままではさらに食料不足に陥ってしまうから。

「食料の安定的な確保の側面や飢餓社会の到来を目前にして快適さを追求する」が理由だから1が正解。
```

```quiz
筆者の言う②<u>今後の課題</u>とは何か。

[ ] 食糧輸入をこれからも続ける必要があるか考え直すこと

[ ] 健康な生活を送るために「快適さ」の基準をどうしていくかということ

[ ] 化学物質汚染の危険性から、輸入食に頼らず生活をしていくこと

[c] 化学物質汚染の危険から身を守り、すこやかな生活を送ること

「食糧輸入を増やしたために化学物質汚染の危険性が増したり、快適さのために食糧生産
に使用した化学物質が食料や環境を汚染することから命を守り、健康な生活を送る」こ
とが今後の課題だから4が正解。
```

```quiz

[ ] 生活者の健康を重視することによって食料や環境が汚染されていることを自覚すべきだ。
```

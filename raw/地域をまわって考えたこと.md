「地方」という言葉がある。それは[[暗黙のうちに]]、「中央」が[[対極]]にあることを前提とした言葉である。

こういう意味での「地方」を、たとえば英語に翻訳するのはむずかしい。ローカルlocalは、「地元」というニュアンスが大きい。以前に他国の日本研究者と話したときには、日本語の「地方」に適した訳は、「周辺 periphery」ではないかという意見もあった。

しかしそのような「地方」は、「中央」からみたときだけ、一律に語れるにすぎない。あたりまえの話だが、実際に訪ねてみれば、それぞれの地域は事情がちがう。「中央」とみなされがちな東京都にも、高齢化に悩む地域は多い。

① <u>こうしたこと</u>は、いわば当然のことだ。だが[[往々にして]]、「中央」「地方」という固定観念、いわば色メガネは根強い。ありがちな「田舎暮らし」の夢では、「地方」は一律に自然にあふれ、人情に満ちているように描かれることがある。あるいは逆に、一律に貧しかったり、所得が低かったりするように描かれることもある。

私は従来から、② <u>そういう「地方」のイメージ</u>には[[懐疑的]]だった。農学部で学んだことがあるので、農林水産業が市場に生産物を出荷する近代産業の一つであること、特別に称賛したり[[卑下する|卑下]]したりするような対象ではないことを、多少は知っていたことも影響しているかもしれない。

ただし③<u>「地方」という言葉が必要とされた</u>[[経緯]]もわかる。日本では戦争のために、都市部の産業が[[壊滅]]し、人口配置と産業構成が変わらざるをえなかった。その歴史が、大都市以外の諸地域に、一定の傾向性をもたらしたことは事実だ。

そのような諸地域を一語で言い表すには、「地方」という言葉は便利である。いちいち「都市部以外の諸地域」と言い換えるのも[[煩雑]]だ。

[[とはいえ]]、「地方」という言葉を使うことで、みえなくなるものもある。それぞれの地域 は、それぞれの地形、気候、土質、水質を持っている。産業構造、交通事情、周辺環境、政治構造なども[[異なる]]。それらの組み合わせからできている地域特性は、「地方」という一律の言葉のもとでは、みえなくなってしまう。

(小熊英二 『地域をまわって考えたこと』 東京書籍による)

- (注1) 対極：比較対象のものがまるっきり反対であること
- (注2) 色メガネ：物事を素直に見ず、持っている考えから偏った見方をすること
- (注3) 懐疑的：ある物事の意味や価値に、疑問を抱くこと
- (注4) 農林水産業：農業や林業、水産業をまとめた言い方
- (注5) 卑下：できの悪いものとしてあえて低い位置に引き下げること
- (注6) 壊滅：ここでは、組織全体が崩れてしまうこと
- (注7) 煩雑：細かく面倒なほど複雑に入り組んでいる様子

## 読解問題

```quiz
①<u>こうしたこと</u>とは何か。

[ ] 中央は異なる事情があるが地方にはないということ
[ ] 中央から見た地方は、同じに見えてしまうこと
[c] 中央と地方には、地域によって異なる現状があること
[ ] 中央とされる場所は、地方と同じ悩みを持っているということ

※実際に訪ねてみれば、それぞれの地域は事情がちがう。中央とみなされがちな東京都にも、高齢化に悩む地域は多い」がこうしたことを表しているから3が正解せいかい。
```

```quiz
②<u>そういう「地方」のイメージ</u>とは何か。

[ ] 地方は、中央に比べ自然が多く人々が穏やかで地域によっては給料が低いこと
[ ] 地方は、中央に比べ自然にあふれているが貧富の差が激しいこと
[ ] 地方は、どの地域も高齢化に悩んでいること
[c] 地方は、自然や人々の思いやりに溢れていたり、生活が苦しかったりすること

※「地方は一律に自然にあふれ、人情に満ちている」と「貧しかったり所得が低かったりする」ことがそういう地方のイメージだから4が正解。
```

```quiz
③<u>「地方」という言葉が必要とされた</u>とあるが、なぜか。

[ ] 日本の歴史上、場所によって環境を変えなければいけなかったから。
[ ] 日本の歴史上、都市と地方の環境の違いを作らなければいけなかったから。
[c] 日本の歴史上、都市とそれ以外の地域の違いが生まれたから。
[ ] 都市の産業の乱れで、人々が他に生活する場所を作らなければいけなかったから。

※「人口配置と産業構成が変かわらざるをえなかった」ことにより「大都市以外の諸地域に、一定の傾向性をもたらした」ことが理由だから3が正解。
```

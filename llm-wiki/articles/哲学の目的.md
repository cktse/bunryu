## 本文
<u>哲学の目的</u>①は[[あくまでも]]問題を解決することです。
幸福になるために哲学をする[[～わけではない|わけではない]]し、
心の安らぎや安定を得るために哲学をやるわけでもありません。
心の安らぎを得るためなら、哲学よりも催眠術や薬を使った方が
[[手っ取り早い]]と思います。

哲学がやっているのは、他の学問と同じく、真理の[[探究]]です。
哲学の問題に対する正しい答えを求めているんです。
だから哲学の研究をしても、幸福になる保証も、
安心が得られる保証もありません。

哲学は幸福や安心を得ることを目標にしているわけではありませんが、
まったく無関係という[[～わけでもない|わけでもありません]]。
なぜかというと、哲学はあらゆる事柄を[[厳密]]に考える学問ですが、
人間は厳密にものを考えないために
<u>不幸になってしまうことが多い</u>②からです。

どうしてものの考え方で不幸になるのかと思うかもしれませんが、
たとえば、「指は六本なくてはならない」と思い込んでいたら、
自分の指が五本しかないことに悩むのではないでしょうか。
こういう悩みは、誤った[[思い込み]]を捨てれば解消します。

（中略）

あるいは、「人生は無意味だ」と思っていれば
幸福な人生を送ることはできないでしょうし、
「[[いかに～べきか|いかに生きるべきか]]という問題には正解がある」と
思っているのに正解が分からなければ、
自分が幸福だと[[確信]]がもてないはずです。
もしそういう考えが間違っていたら（ぼくは間違っていると思いますが）、
考え違いのために不幸になっていると[[～しかない|言うしかありません]]。

（土屋賢二『幸・不幸の分かれ道 考え違いとユーモア』東京書籍による）

## 語釈
- 催眠術（さいみんじゅつ）— 暗示によって特殊な心理状態を作り出す術。
- あらゆる — すべての。「あらゆる事柄」＝すべての物事。
- 考え違い（かんがえちがい）— 誤った思い込み・勘違い。

## 注目語彙・文法
語彙:
- [[あくまでも]] — 第1段落。「あくまでも問題を解決する」。
- [[手っ取り早い]] — 第1段落。「使った方が手っ取り早い」。
- [[探究]] — 第2段落。「真理の探究」。
- [[厳密]] — 第3段落。「厳密に考える学問」。
- [[思い込み]] — 第4段落。「誤った思い込みを捨てれば」。
- [[確信]] — 第6段落。「自分が幸福だと確信がもてない」。

文法:
- [[～わけではない]] — 第1段落。「哲学をするわけではない」。
- [[～わけでもない]] — 第3段落。「無関係というわけでもありません」。
- [[いかに～べきか]] — 第6段落。「いかに生きるべきか」。
- [[～しかない]] — 第6段落。「言うしかありません」。

## メモ
テーマ：哲学の目的とは何か。土屋賢二の随筆。哲学の目的は幸福や安心ではなく
「問題を解決すること＝真理の探究」であるが、厳密に考えないことで生じる誤った
思い込みを正すという点で、幸福とも無縁ではない、と説く。部分否定（わけではない／
わけでもない）、疑問の埋め込み（いかに〜べきか）、限定・唯一の選択（〜しかない）
などを文脈で学べる。末尾に読解問題（quizblock）を収録。原文ファイル名・本文
タイトルはともに「哲学の目的」。

## 読解問題

```quiz
①<u>哲学の目的</u>とあるが、筆者の考えに近いものはどれか。
[ ] 幸福や安らぎを得るために、問題を解決していくことだ。
[ ] 手段を選ばず問題を解決することだ。
[ ] 真理の探究によって、幸せを手に入れることだ。
[c] 哲学問題に誤りのない答えを追い求めることだ。

「幸福や安らぎを得る」は哲学の目的ではない
「手段を選ばず」とは言っていない
「幸せを手に入れること」は哲学の目的ではない
```

```quiz
②<u>不幸になってしまうことが多い</u>のはなぜか。

[c] 厳密にものを考えないゆえに人は誤った思い込みをするから。
[ ] 「人生は無意味だ」と思って人生を送っているから。
[ ] 哲学とはあらゆる事柄を厳密に考える学問だから。
[ ] 深く考えることなく行動することで人は過ちを犯すものだから。

「人間は厳密にものを考えないために誤った思い込みをしてしまい不幸になる」ことが理由だから1が正解。
```

```quiz
この文章で筆者が最も言いたいことは何か。

[ ] 不幸になるのは、幸福になりたいという人間の思いが強いからだ。

[c] 不幸とは、人間のいい加減な認識によるものだ。

[ ] 不幸になってしまうことは、哲学で解決することはできない。

[ ] 不幸になってしまうのは、哲学が幸福や安らぎを保証しないからだ。

「厳密に考えないこと（＝いい加減な認識）で誤った思い込みをし不幸になる」ことが最も言いたいことだから2が正解。
```
